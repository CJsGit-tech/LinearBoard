# Format an existing QA record

Read this reference only for an authorized retrospective or format-only rewrite of an existing milestone QA Project Document.

Reuse the native document and preserve its identity, title and project parent unless a rename or move is authorized. Before rewriting, inventory original questions and answers, revisions, requirement IDs and linked PRDs.

- Use headings and bullet lists throughout; convert context, indexes, summaries and migration tables without losing information or links.
- Retain each original answer separately from interpreted rules and later corrections. Keep original option labels, recommendations and user choices distinguishable.
- Do not transform a free-form answer into acceptance of an option. Label non-verbatim summaries as summaries.
- Recover examples, options and tradeoffs only from available source material. Mark retrospective paraphrases and unavailable history; never invent wording, numbering, dates, approvals or answers.
- Preserve superseded and not-applicable decisions. Missing historical detail does not reopen a settled product rule.

For format-only work, do not mutate PRDs or their states. Re-read immediately before saving and reconcile concurrent edits. After saving, compare retained answers, decisions, revisions, requirement IDs and links with the pre-edit inventory. Confirm bullet formatting, preserved dispositions and that no proposal became active. Matching counts alone are insufficient proof.
