# M04 — Mobile Design Book of Trends 2015–2016

**Source:** UXPin, *Mobile Design Book of Trends 2015 & 2016*, copyright 2015; Jerry Cao, Carrie Cousins and Ryan Thomas Riddle. Original filename: `Mobile Design/Mobile Design Book of Trends 2015-2016.pdf`. Locators are PDF pages.

## Structure and overlap

The six sections cover gestures (pp. 8–25), layers (26–41), typography (42–62), flat design (63–81), microinteractions (82–99) and cards (100–123). The typography, flat and card sections substantially overlap [T01](T01.md), [M01](M01.md) and [M03](M03.md), with changed pagination and some examples. Do not count repeated claims as independent research.

## Gestures

- **Specify the physical action, location and discoverability.** A name such as swipe alone does not define the task (pp. 8–11, 19–21). SoundCloud and Clear use similar motions for different functions, so visual signifiers and context matter (pp. 20–21).
- **Keep a usable route alongside a complex shortcut.** The book quotes guidance to use complex gestures as shortcuts rather than the only way to complete a task (p. 15). Preserve familiar gesture meanings where appropriate; do not invent hidden actions just to reduce visible controls.
- **Model the interaction lifecycle.** Initiation, continuation and termination help explain dragging and release in the Angry Birds example (pp. 17–18). Consider cancellation or reversal while an action is underway; this last recommendation is synthesis.
- **Account for different holds and reach.** The text explicitly includes either hand, two hands, landscape and a device resting on a table (p. 19). Its earlier one-thumb generalization (p. 11) is not evidence that all users operate that way.

## Layers and adaptation

Depth and surface boundaries can communicate which content belongs together and which surface is above another (pp. 26–30). The Reddit drawer illustration retains a dimmed underlying view (p. 29), while the adaptive grid diagram (p. 31) illustrates relationships across widths. Use a layer for a meaningful relationship, not as a default container around every element.

The source describes reveal, transform, expand, reflow and divide as adaptive behaviors (p. 32). Choose a behavior that preserves the user's task and location. A list becoming multiple columns is not the only available response to more space; this is design-pro synthesis.

## Microinteractions and feedback

The book attributes a four-part model to Dan Saffer: trigger, rules, feedback, and loops/modes (pp. 86–87). This is a secondary discussion in the reviewed UXPin book; it does not establish that Saffer's original book was reviewed.

- Identify what starts the interaction, what actually changes, how the user learns the result and what changes on repetition (pp. 83–89).
- Make feedback understandable and connected to the task. Slack's pictured interactions include message updates, attachments and notifications (pp. 83–84); the check-off example distinguishes pending from completed items (pp. 88–89).
- Evaluate repeated use. A flourish that is entertaining once can become annoying after many repetitions (p. 89).
- Match copy to the moment using only useful text; keep feedback related to the parent interface and consider subsequent interactions (pp. 90–91).

**Design-pro applications:** for chat, distinguish sending, response progress, completion and failure, and attach retry to the failed operation. Preserve content during a recoverable failure and avoid communicating success before it has occurred. For a simulated signup, report the simulation honestly. These apply the feedback model; the book does not prescribe these exact chat/signup states.

## Typography, flat design and cards

Spacing marks related versus new thoughts (pp. 46–48); alignment depends on reading length (49–50); responsive type should not force desktop wrapping (57–58). Use the historical type/contrast cautions in [T01](T01.md).

Readability and control separation matter more than a strict flat aesthetic (p. 71). Card conversation grouping uses proximity (p. 111); detail can expand while retaining context (p. 119). The source repeats the favorable description of disguised advertising and tiny dismiss targets (pp. 104–106); reject that treatment for the reasons in [M03](M03.md#exceptions-and-source-critique).

## Limits and decisions not to copy

- The 30-, 44- and 70-point target claims (p. 11) do not supply a universal minimum for all platforms, devices or abilities. Verify current native guidance or [web criteria](../current-accessibility.md#target-size); do not relabel points as CSS pixels.
- 3D Touch and iOS 9 behavior (pp. 14–15, 92–94), Material Design Lite (p. 36), particular framework recommendations, breakpoints and gutters (p. 32) describe the publication period. They are not current API or SDK instructions.
- Claims that a fling cannot be undone (p. 17) describe a particular interaction model, not a prohibition on product-level undo.
- Animation is presented as central or essential to feedback (pp. 11–13, 92). Feedback can also be textual or otherwise nonmoving; do not make motion the only means of conveying a result. This is a design-pro qualification.
- “Addictive,” “invisible” and engagement claims (pp. 82, 94, 98) are framing, not success criteria. Favor understandable status and user task completion. Avoid interpreting invisible mechanics as hidden feedback.
- All “what's next” passages are predictions from 2015. Screenshots are static evidence of visual composition and do not verify the depicted animations or usability outcomes.
