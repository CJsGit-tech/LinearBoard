# resolve — 完成指定設計問題

## Responsibility

Can you diagnose and finish this scoped design problem without making me choose the internal workflow?

Read the [shared execution contract](../execution.md) and the applicable mode.

## Execute

Establish the concrete outcome and preservation constraints. Diagnose the cause using the available evidence, select the smallest relevant responsibilities from these command contracts, and execute authorized changes. Name the chosen intervention briefly; do not run every command or require a separate audit approval. Resolve blocking task/state problems before decorative refinements. Reinspect and verify the result against the original criteria. If evidence contradicts the diagnosis, revise the approach within scope. Ask only when a consequential missing decision prevents correct work. Stop when the outcome is demonstrated or report the precise unmet requirement that cannot be resolved with current access/context.

## Creative application

If the scoped problem is interchangeable design, distinguish a missing product idea from weak composition or a component detail. Use [concept development](../concepts/creative-design.md#concept-development), [composition](../concepts/creative-design.md#composition-and-visual-tension) or [shape](../concepts/creative-design.md#expressive-component-shape) accordingly. Removing borders alone does not supply a missing concept; adding spectacle does not resolve a broken task.

Develop and choose the appropriate intervention when the user delegates that judgment. Preserve the brief, established identity and edit scope. Inspect the rendered result, revise a concrete weakness and check the affected operation. Explain the decisive choice and observed revision; do not run all creative methods for a minor correction or rewrite the project as a different product.

## Platform focus

- **Web:** choose the relevant composition, component, task and browser checks.
- **Mobile:** choose the appropriate platform contract and real runtime evidence where available.

## Deliver and finish

the finished scoped correction, concise rationale and verification evidence; --review returns the proposed intervention only.

Completion: the original requested outcome is supported, required behavior is preserved and the report states material unverified boundaries.

## Example

```text
$design-pro resolve web "The game header feels detached. Integrate it with the page, preserve the artwork and existing navigation"
```
