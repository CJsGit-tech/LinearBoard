# Typography

Use type to make the reading order and message clear, and give expressive brand moments a defined role.

## DO

- Test real text, the actual script, font fallback and viewport. [T01, pp. 6–11, 24–26](../books/T01.md)
- Keep a stable reading edge for longer text and use centering for short headings or actions. Adapt the edge to the language's direction. [T01, pp. 15–17](../books/T01.md#decisions-worth-retaining)
- Inspect text and image crops together and keep meaningful subjects visible. [T02, pp. 16–18](../books/T02.md#practical-techniques)
- Document type by role with rendered examples and variants. [S02, pp. 29–30](../books/S02.md)
- Set line length and leading by testing the actual text. Source figures (40–70 characters per line, 1.3–1.5 leading) are starting points for Latin text. [T01](../books/T01.md#measurements-and-exceptions); [T02](../books/T02.md#exceptions-and-evidence-limits)

## DON'T

*(synthesis; current web checks are in [accessibility sources](../current-accessibility.md))*

- Do not remove semantic headings to simplify a visual scale; restyle them.
- Do not use motion to rescue unreadable text; fix its size or contrast.
- Do not copy pale gray text from a historical screenshot; measure contrast on the actual pair.

## Guidelines and example

A game title can use an expressive display treatment while its date and platform details use a restrained readable style. A chat transcript needs reading rhythm, long-message wrapping and legible status text. Across device widths, change the visual role and keep the meaning. Check contrast and reflow on the rendered result.

## Tone, hierarchy and actual text

Choose treatment by the message's role and reading context. A title may be expressive; a necessary error stays direct and legible. Base audience claims on research with that audience. [U11, pp. 46–56](../books/U11.md#typography-supports-meaning-it-cannot-replace-it)

Inspect each actual foreground/background combination. Use as many hierarchy levels as the content has roles. [U11, pp. 57–69](../books/U11.md#hierarchy-by-role-rather-than-a-fixed-quota)
